# Heart Disease Risk Predictor

## Live Demo
https://huggingface.co/spaces/Sailaja0031/heart-risk-predictor

## Problem Statement
Heart disease is a leading cause of death worldwide.
This app predicts heart disease risk instantly using Machine Learning.

## Technologies Used
- Python 3
- Scikit-learn (ML Model)
- Gradio (Web App)
- Pandas and NumPy (Data Processing)
- Joblib (Model Storage)
- FPDF2 (PDF Reports)
- HuggingFace Spaces (Deployment)

## How It Works
1. User enters medical details
2. ML model analyzes the data
3. App predicts Heart Disease Risk
4. Generates a PDF report
